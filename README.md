# Dev Console

This project is a dashboard designed to boost developer's productivity by integrating multiple sites in a single dashboard.

## Getting Started

To get started with the Dev Console, clone the repository and install the dependencies:

```bash
git clone https://github.com/sedhuz/dev-console-web.git
cd dev-console-web
npm install
```

Then, run the development server:

```bash
npm run dev
```

You can now access the application at `http://localhost:5173`.
Note : the flask backend must be setup, before running this

Refer : https://github.com/sedhuz/dev-console-server.git
